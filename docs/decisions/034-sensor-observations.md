# 034. Тестовая версия сигнатур и наблюдений

9 ноября 2026. Первый срез [проекта F2+F3](../research/fog-visibility/signatures-and-knowledge.md).

Сигнатуры и детекторы объявляются в опциональном `Sensors` объекта. Без явного списка сигнатур объект имеет `visual`. Строковые имена компилируются в ordinal ID внутри мира. Круговые детекторы указывают канал, сигнатуру, дальность между центрами в XY и разрешённое представление. Несколько успешных наблюдений дают лучшее представление и объединяют разрешения чтения полей. В этом срезе живая модель доступна через оптический канал. Обычный `Vision.Radius` использует покрытие F1.

`Concealments` задаёт требуемый counter канала и опциональный terrain. Один детектор должен преодолеть все применимые ограничения своего канала. Положение и текущий terrain читаются при наблюдении. `GrantSignature`, `GrantConcealment` и `RevokeSensorGrant` работают на потоке симуляции с отдельными tokens и сроками. Подавление сигнатуры действует, пока остаётся хотя бы один token подавления.

Knowledge текущего контакта хранит непрозрачный ID игрока, XY, известный тип и тики измерения и идентификации. Непрерывное сопровождение сохраняет ранее опознанный тип. После полного разрыва новый контакт получает новый ID. У живой оптической модели приоритет над маркером. Контакты не меняют историю terrain и не дают права на адресную команду.

HP и наложенные состояния отсутствуют в записях Knowledge. Детектор может разрешить их чтение в момент публикации кадра. Когда этот детектор уходит, следующий кадр перестаёт выдавать разрешённые им поля. Для обычного визуального наблюдения действуют текущие правила F1. Ограничения специальной оптики применяются к кадрам и событиям об изменении HP.

`Visible` с подключёнными сенсорами открывает terrain и базовый оптический обзор. Условия скрытности и дальности специальных детекторов продолжают действовать. Фильтрация кадра использует список игроков независимо от наличия поля тумана. Модели, оружие и контакты публикуются в закреплённом слоте. Журналы F1 без `Sensors` сохраняют прежний формат состояния. Хеш версии с сенсорами включает активные grants, номера контактов и компактные факты сопровождения.

Полигон `./tools/dev.sh run --sensors` использует стрелка с лесным камуфляжем, танк с оптическим детектором и ДОТ с двумя дальностями радара. F8 меняет наблюдателя. На миникарте жёлтая точка обозначает анонимный контакт, рамка обозначает опознанный. Для диагностики первого кадра есть `--verify-sensors`.

Пространственный индекс строится для текущих позиций. Широкие запросы с числом потенциальных bins выше бюджета проходят по списку целей. Проход используется как последовательная исходная версия для дальнейших замеров. Глушение, снимки зданий и периодическое сканирование запланированы отдельными срезами. Будущий снимок здания по умолчанию хранит данные, необходимые для отрисовки. Расширение его состава задаётся явным списком полей конкретной игры.

# Источники исследования слоёв навигации

Получены 4 ноября 2026 года через GitHub connector. Для OpenRA разрешён ref `bleed` в commit `9636b63eaee62fcb60ef2e896e7985bdf2f1ee68`; Recoil и 0 A.D. прочитаны на тех же закреплённых commit, что и [предыдущее исследование](../rts-group-navigation/engine-patterns.md). Ссылки ниже привязаны к commit, а не подвижной ветке.

Файл целиком получен для проверки контекста, но чтение сосредоточено на перечисленных функциях и структурах. Здесь нет утверждения о построчном аудите всего движка. Не выполнялись игры, замеры чужих движков или проверки их численной воспроизводимости; GPL исходники не сохранялись в коде OpenRTS и не переводились в C#.

## Ограничения и проверка выводов

Гипотезы «enemy blocker не уничтожает terrain reachability», «раздельный stop/traverse», «точные позиции поверх grid route» имеют непосредственные подтверждения в N001–N009. Конкретная архитектура знания игрока, геометрических зон огня, группового пересечения capabilities и ключей кэша — наши предложения; эти механизмы не приписываются референсам без отдельной проверки.

Флаг приказа в shroud не эквивалентен отсутствию утечки информации через поисковую карту. Не подтверждены текущим чтением: полноценная player-specific memory map, общая поддержка навигации по произвольной 3D геометрии, сфер/конусов опасности и универсальная гарантия разрешения заторов. Для мостов подтверждена конкретная слойная реализация OpenRA с перечисленными ограничениями.

Два первоначально предполагаемых пути (`OpenRA.Mods.Common/Traits/Interfaces.cs` и `0ad/source/simulation2/helpers/Obstruction.h`) вернули 404. Они не используются как источники. Остальные ссылки получены успешно. Непроверенные источники и пересказы чужих бенчмарков в выводы не включены.

# Архитектура ИИ для RTS

Исследование, 5 ноября 2026. Статус: аналитический материал и гипотезы, не принятое архитектурное решение и не план реализации. Рассматривается противник в skirmish OpenRTS; кампанийный сценарный ИИ, полноценная дипломатия, сетевой протокол и обучение модели не проектируются.

**Главный вывод.** Разделение на стратегию, специализированные направления и боевые группы хорошо согласуется с изученными примерами. Но это две независимые оси — уровень абстракции и область ответственности, а не обязательная цепочка из трёх классов. Для работы важнее ясные правила владения юнитами, распределения средств, общая ограниченная информация и локальная реакция. Высокоуровневая стратегия задаёт цели и ограничения, а не участвует в каждом решении.

Первый прототип разумно проверить на обычном детерминированном наборе правил с одним противником. Генерал, тактические режимы, карты угроз и внешний LLM — варианты развития, а не обязательные предварительные условия. Оценка силы, стоимость вычислений и даже польза иерархии в OpenRTS пока не измерены.

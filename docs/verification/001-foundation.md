# Проверка первого рабочего каркаса

Исторический отчёт первого этапа. Актуальные проверки включают [навигацию](003-navigation.md).

3 ноября 2026 года. Окружение: macOS, Apple M3 Max, .NET SDK 10.0.105, runtime 10.0.5, Godot 4.7.2 .NET. Графический запуск использует OpenGL Compatibility поверх Metal.

- Solution из семи проектов собран без ошибок и предупреждений.
- Пройдены 20 импортированных проверок DeclarativeContent и 4 проверки OpenRTS.
- SHA-256 всех 9 импортированных файлов совпадают с манифестом исходного коммита Hyperfleets.
- Отчёты headless и Godot совпадают: 2 конкретных определения, отпечаток `AF15F2050C694C0BFD29613029141482B5E1D1FA1453A2CB45FB6E5374EE8484`.
- Godot headless проверен с 1, 10000 и 10001 экземпляром MultiMesh. Ошибочные HP и количество маркеров завершают проверку кодом 1 с диагностикой.
- На настоящем графическом backend проверены transforms последнего маркера для 10000 и 10001 экземпляра.
- Окно стенда с 10000 статических маркеров проверено визуально: сетка отображается, русская диагностическая панель читается.

Повторяемая команда — `./tools/dev.sh verify`. Для отдельной проверки графического backend:

```sh
./tools/dev.sh run --verify --count=10000
./tools/dev.sh run --verify --count=10001
```

Headless dummy renderer не проверяет GPU transforms; для этого нужен графический запуск. Эти проверки не измеряют FPS, время тика, навигацию или бой. Экспорт на Windows и Linux ещё не проверен.

В ограниченном окружении проверка .NET потребовала запуска вне sandbox из-за работы системных IPC. Для восстановления пакетов использован существующий локальный NuGet кэш; конфигурация репозитория указывает стандартный NuGet источник, а пути Hyperfleets не являются зависимостями проектов.

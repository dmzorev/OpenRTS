# Проверка фиксированного тика и представления

3 ноября 2026 года. macOS ARM64, Apple M3 Max, .NET SDK 10.0.105 и Godot 4.7.2 .NET.

- Debug solution и Release headless собраны без предупреждений и ошибок.
- Пройдены 20 проверок DeclarativeContent и 18 проверок OpenRTS.
- Проверены точное прибытие, минимальная диагональная скорость, большие координаты и ограничение длины шага.
- Порядок пакета не меняет порядок применения команд. Неверный пакет не продвигает авторитетное состояние.
- Удаление из плотного массива сохраняет ID, ID не переиспользуются. События удаления сохраняют позицию и тип.
- Эквивалентные миры с разным физическим порядком хранения получают одинаковые случайные цели и хеш.
- Проверены известные векторы RNG, нулевые managed аллокации установившегося Step на 10000 объектах, закрепление кадров и пропуск публикации при занятом пуле.
- Проверены совпадение direct и worker, конечная публикация, изменение wall-clock темпа, доставка событий при пропуске кадров и явная ошибка переполнения очереди.
- Проверены передача ошибки worker, остановка, повторный Dispose, три перезапуска и воспроизведение фактически применённого живого ввода.
- Сквозные сценарии на 1, 10000 и 10001 объектах выполняют 64 тика. Результаты direct headless и Godot с worker совпадают при лимитах 15 и 120 FPS. Отдельный запуск проверяет paced worker 25 Гц с представлением 15 FPS.
- Настоящий OpenGL backend проверен на тех же трёх размерах: интерполяция alpha 0,5, пустое представление и повторное использование ёмкости MultiMesh.
- Debug и Release headless дают одинаковый отчёт на 10000 объектах после 64 тиков: `286677C286FC5C4078677C4199ED0DC92B1CD2AD2FB8A5DF6ED252A400531431`.

Повторить функциональные проверки:

```sh
./tools/dev.sh verify
./tools/dev.sh run --verify-simulation --count=10000 --ticks=64
./tools/dev.sh headless --simulate --count=10000 --ticks=64
```

Старый статический режим `--verify` сохранён для регрессионной проверки загрузки и MultiMesh. Headless dummy renderer не подтверждает позиции на GPU; поэтому интерполяция отдельно проверяется с настоящим графическим backend.

Release измерения сохранены в [measurements.json](../research/simulation-foundation/measurements.json). Они измеряют только прямое движение внутри World.Step, не полную RTS нагрузку. Навигация, столкновения, бой, чанки большой карты, сохранение/восстановление и Windows/Linux пока не проверялись.

В манифест импорта DeclarativeContent добавлена отдельная контрольная сумма существующей локальной правки README. Исходная SHA-256 и commit сохранены; исходники библиотеки и её лицензия не менялись.

# OpenRTS

OpenRTS — движок для desktop RTS на C# с независимой симуляцией и адаптером Godot .NET. Ядро предоставляет фиксированный тик, команды и ECS, а готовые модули добавляют навигацию, бой, способности и производство. 2D- и 3D-полигоны показывают, как собрать игру из этих компонентов. Движок распространяется под [MIT](LICENSE).

Симуляция работает с наземным миром 2.5D. Godot отвечает за сцену, ввод и отображение, а headless-хост запускает те же игровые правила без графики. Цель по масштабу — большие карты и от 10 000 объектов. Движение, бой, поиск путей и отображение измеряются отдельно.

## Быстрый старт

Понадобятся Bash на macOS и Linux или PowerShell 7.3+ на Windows, а также .NET SDK 10.0.105 или более новый patch той же feature band. Для графического запуска и редактора нужен Godot 4.7.2 .NET. [Настройка окружения](docs/development.md#окружение).

Команды для macOS и Linux.

```bash
./tools/dev.sh run       # Главное меню 2D-полигона
./tools/dev.sh headless --mod=sandbox/game.yaml  # Симуляция без Godot
./tools/dev.sh editor    # Редактор карт Godot
./tools/dev.sh test      # Сборка и тесты
```

Команды для Windows.

```powershell
pwsh -File .\tools\dev.ps1 run
pwsh -File .\tools\dev.ps1 test
```

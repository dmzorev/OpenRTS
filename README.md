# OpenRTS

Самостоятельный RTS движок на C# с независимой симуляцией и интеграцией с Godot .NET. Код движка распространяется под MIT.

Подготовлена документация для начала реализации. Исходного кода движка, Godot проекта и команд сборки пока нет.

- [План работы и распределение решений](docs/plan.md)
- [Архитектурные договорённости](docs/architecture.md)
- [Референсы для исследования систем](docs/references.md)
- [Лицензия MIT](LICENSE)

OpenRTS создаётся независимо от OpenRA. Совместимость с его API, модами, форматами и реплеями не требуется. OpenRTSv1 остаётся отдельным исследовательским проектом; извлечённый из OpenRA код не переносится в MIT ядро.

Из Hyperfleets планируется переиспользовать самостоятельную MIT библиотеку DeclarativeContent. Проверка и перенос библиотеки вместе с её тестами входят в первый этап реализации.

Godot служит для ввода, сцены, интерфейса и звука. Headless приложение использует ту же симуляцию без Godot. Для тяжёлых систем предусмотрены рабочие потоки и воспроизводимый порядок применения результатов.
